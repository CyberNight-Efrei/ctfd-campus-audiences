Campus Audiences

Ce plugin synchronise les audiences des joueurs depuis un Custom Field et affecte les challenges aux modules à partir de leurs tags.

Compatibilité CTFd

Le plugin détecte les capacités de ton checkout. Si les modèles natifs Audiences/Modules et le champ Challenges.module_id existent, il utilise les tables natives de CTFd. Sinon, il utilise ses propres tables de compatibilité (notamment pour le tag officiel 3.8.0).

Synchronisation

Une synchronisation complète est effectuée au démarrage de CTFd. Les changements de Custom Fields, d'appartenance aux équipes et de tags sont ensuite traités automatiquement.

Configuration

Modifie settings.json dans le répertoire du plugin, puis utilise le bouton ci-dessus pour réappliquer la configuration.

  • user_field : nom du Custom Field utilisateur.
  • team_field : nom du Custom Field équipe (par défaut : même nom que user_field).
  • campus_to_audience : valeur du champ vers nom d'audience.
  • tag_to_module : tag vers nom du module.
  • module_to_audiences : audiences autorisées pour chaque module.
En mode Teams, le Custom Field équipe team_field (par défaut le même nom que user_field) est la source de vérité pour l'audience. Tu peux le remplir manuellement : sa valeur est utilisée même si aucun membre n'a de Campus.
Si le champ équipe est vide, le plugin tente de le calculer depuis les Custom Fields des membres. Il le remplit si au moins un membre possède un Campus et si toutes les valeurs renseignées sont identiques. Les membres sans Campus sont ignorés. En cas de conflit entre deux valeurs renseignées, ou si aucun membre n'a de Campus, le champ reste vide. Les valeurs générées par le plugin sont suivies séparément : elles peuvent être mises à jour ou supprimées, tandis qu'une valeur saisie manuellement est conservée et ne sera jamais écrasée par le calcul automatique. Toute modification manuelle faite dans CTFd est mémorisée, même si la valeur correspond aux Campus des membres.
Si aucun Custom Field équipe correspondant n'existe, le plugin calcule directement l'audience à partir des valeurs non vides et concordantes des membres.
Si ton checkout ne contient pas les modèles natifs Audiences/Modules, les modules et audiences restent gérés dans les tables internes du plugin et ne sont pas affichés dans l'interface d'administration native de CTFd.
