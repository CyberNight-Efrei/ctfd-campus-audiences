Campus Audiences

Ce plugin synchronise les audiences des joueurs depuis un Custom Field et range les challenges dans des modules en fonction de leurs tags.

Synchronisation

Une synchronisation complète est effectuée au démarrage de CTFd. Les changements de Custom Fields et de tags sont ensuite traités automatiquement.

Configuration

Modifie le fichier settings.json dans le répertoire du plugin, puis utilise le bouton ci-dessus pour réappliquer la configuration.

  • user_field : nom du Custom Field utilisateur.
  • campus_to_audience : valeur du champ vers nom d'audience.
  • tag_to_module : tag vers nom du module.
  • module_to_audiences : audiences autorisées pour chaque module.
Les challenges sans tag configuré restent publics. Si plusieurs tags d'un challenge correspondent à des modules différents, le challenge est placé dans un module de conflit inaccessible aux joueurs. Les administrateurs conservent l'accès à tous les challenges.

CTFd 3.8.9 : les audiences et modules sont stockés dans des tables propres au plugin ; cette version de CTFd ne fournit pas encore ces modèles nativement.
